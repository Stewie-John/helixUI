# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Include
the HelixUI version, installation method, operating system, Node.js version,
browser, relevant agent CLI version, and concise reproduction steps.

Before posting logs or screenshots, remove:

- prompts and model responses
- credentials, tokens, cookies, and authorization headers
- usernames, email addresses, hostnames, and IP addresses
- workspace paths, file contents, session identifiers, and project names

General installation and configuration guidance is maintained in the
[README](README.md) and [deployment documentation](docs/DEPLOYMENT.md).

Do not use a public issue for an exploitable vulnerability. Follow the private
reporting process in [SECURITY.md](SECURITY.md).
